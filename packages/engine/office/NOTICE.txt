Recto's Office conversion package
=================================

This package is downloaded only when you agree to it, the first time you open a Word, Excel
or PowerPoint file in Recto on a computer or tablet. It is kept on your device and runs only
there. It is not part of Recto's own code, which is licensed under Apache-2.0 (Recto's NOTICE
and LICENSE files).

Source: https://git.libreoffice.org/core (the libreoffice-24-8 branch)

@matbee/libreoffice-converter 2.7.2
-----------------------------------
The WebAssembly build of LibreOffice and its worker host (soffice.js, soffice.worker.js,
soffice.wasm, soffice.data, browser.worker.global.js), from the npm package
@matbee/libreoffice-converter 2.7.2.
License: Mozilla Public License 2.0 (MPL-2.0.txt).
Source: https://github.com/matbeedotcom/libreoffice-document-converter

Modification: Recto changes one line of soffice.js. "var pthreadPoolSize=4;" becomes
"var pthreadPoolSize=16;": with four pre-started threads, LibreOffice can wait forever while
it loads a document. The modified file is served beside this notice, and the change is
recorded in Recto's source (packages/engine/office/office.lock.json and fetch.ts,
https://github.com/ErenDenizK/pdf-editor). Every other file is unmodified.
