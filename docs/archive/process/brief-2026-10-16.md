# Owner brief, 2026-10-16 (R21): one standard for the glass and the UI before user tests

The owner dictated this brief in Turkish after trying the R19/R20 deploy (1693c78). Each item is
restated as a task prompt, with the owner's words where they set the intent. Decisions taken from
it are in `decisions.md` (GLS-20, DSN-46…, MOB-18, PRC-18). Nothing here is dropped: an item is
done, scheduled in a wave, or parked with a reason.

The goal (B-16): after the glass and UI share one standard and the scroll bars are in, the owner
starts **real user tests**. The build must be the most presentable one: clean, consistent, no
repeated text, no leftover UI.

| Id | Prompt | Owner's intent | Wave / lane |
|---|---|---|---|
| B-1 | **Fix the glass tone to the theme.** Light theme → light glass, dark theme → dark glass, always. Remove the adaptive turn (GLS-9) from chips, bars, the page pill and the phone's pieces, and the split top's page-following scroll edge (DSN-40); GPU glass draws the theme's tone.
