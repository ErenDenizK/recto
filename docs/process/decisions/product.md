| PRD-19 | **Text (.txt) to PDF, no dependency.** Opening or dropping a file named `*.txt` (a text/plain type alone is not enough; not `.log`, `.csv`, `.md`) creates a new, unsaved document `<name>.pdf`, made like an image's document: its pages are the converted PDF's, it is one history entry (it counts as changed, closing it asks) and it is not added to Recents. Only files dropped or picked themselves convert, not text files inside a dropped folder; over 2 MB a toast refuses it. Decoding: a UTF-16 BOM means UTF-16; else UTF-8 when the bytes are valid UTF-8 (BOM stripped); else windows-1254 when valid in it (legacy Turkish files); CRLF/CR become LF, tabs four spaces, a form feed a page break. Layout in the engine with the bundled Noto Sans, 11 pt, line height 1.4, 72 pt margins, the default page size (A4), the paragraph line-breaker (`text-edit/linebreak`, no new breaker); blank lines kept, over-long words break by character, an empty file is one blank page; the text is real and extractable. Entry points: Open files, drop, and the palette command "Text to PDF…" / "Metinden PDF…" (picker on .txt); none on the phone or in the Library. | 2026-10-20 | CEO, 2026-10-20, conversion memo step 2; review changes | In force |
